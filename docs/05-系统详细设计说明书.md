## 1. 详细设计概述

### 1.1 设计目标

在概要设计的架构约束下，对系统的**前端页面、后端模块、数据库表、对外接口、
算法引擎契约**进行到类/组件/字段级的细化设计，作为编码实现与联调的直接依据。

### 1.2 设计原则

- **前后端分离**：Vue 3 SPA 通过 REST API 与后端交互，认证依赖 Session-Cookie；
- **后端分层**：Controller → Service → Mapper（MyBatis-Plus）三层结构；
- **算法外置**：Java 后端通过 `ProcessBuilder` 调用 Python 算法脚本，JSON 行协议通信；
- **配置外化**：数据库 / Redis / Python 路径均在 `application-dev.yml` 中声明。

### 1.3 涉及范围

| 层 | 技术 | 关键目录 |
| --- | --- | --- |
| 表现层 | Vue 3 + Vite + Element Plus + ECharts | `frontend/src/views` |
| 业务层 | Spring Boot 3.5 + Spring Security | `backend/src/main/java/com/alvis/media` |
| 数据层 | MySQL 8 + MyBatis-Plus + Redis | 库 `anime_mangage_db`（13 张表） |
| 算法层 | Python 3.10 + scikit-learn / LightGBM / PyTorch | `algorithm/{prediction,recommendation,eda}` |

**t_user_video_operation —— 用户-动漫操作（评分/点赞/收藏）**

| 字段 | 说明 |
| --- | --- |
| id | 用户ID（联合主键一部分） |
| video_id | 动漫ID |
| thumb_up | 是否点赞 |
| collection | 是否收藏（"我的追番"数据来源） |
| rating | 评分（用于协同过滤与评分分布分析） |
| finally_active_time | 最后操作时间 |

**t_video_play —— 播放统计**

| 字段 | 说明 |
| --- | --- |

| play_times | 累计播放次数 |

### 2.4 标签与关联表

- **t_video_tag（video_id, tag_id, video_property_flag）**：动漫-标签关联
- **t_tag（tag_id, tag_name）**：标签字典（题材/关键词）
- **t_user_tag（user_id, tag_id, user_property_flag）**：用户-标签关联

### 2.5 消息与日志表

- **t_message / t_message_user**：站内消息主表与接收明细
- **t_user_event_log**：用户事件日志（登录/登出等，供活跃度趋势统计）
- **t_role / t_user_role_relation / t_user_token**：角色与令牌

### 2.6 索引与约束

- 主键：所有表均有主键（见上）；
- 外键不落库（由应用层保障），利于大批量数据导入性能；
- 逻辑删除：`t_user.deleted` 标记，查询默认 `deleted=0`。

### 3.3 统一响应格式

所有接口返回 `{ "code": int, "message": string, "response": object }`：

| code | 含义 |
| --- | --- |
| 1 | 成功 |
| 401 | 未登录/会话失效 |
| 403 | 无权限 |
| 500 | 系统内部错误 |

### 3.4 安全设计（Spring Security）

- 自定义 `RestLoginAuthenticationFilter` 拦截 `POST /api/user/login`，JSON 解析用户名/密码；
- `RestAuthenticationProvider` 完成认证，principal 为 `UserDetails(User)` 对象；
- `HttpSessionSecurityContextRepository` + **Spring Session Redis** 持久化会话
  （JDK 须为 **17**，新 JDK 反序列化不兼容会导致会话读取失败）；
- 鉴权：`/api/admin/**` 需 ADMIN 角色，`/api/recommend`、`/api/predict` 放行；
- `RestAuthenticationSuccessHandler` / `RestLogoutSuccessHandler` 输出标准 JSON，
  登出处理器已做 `authentication` 空指针与类型防御；
- `WebContext.getCurrentUser()` 优先读请求属性，回退解析 `SecurityContext`
  principal，均带 `instanceof` / null 保护。

### 3.5 Python 调用契约（RecommendServiceImpl / PredictServiceImpl）

- 相对路径解析：`../.venv/Scripts/python.exe`、`../algorithm/...`（工作目录=backend）；
- 参数传递走子进程命令行，stdout 输出**单行 JSON**（stderr 告警行在 Java 侧丢弃）；
- 退出码非 0 → 抛 `RuntimeException`；
- 结果解析：取最后一行非空 JSON → 组装 VM → 数据库补全动漫详情 → Redis 缓存 1 小时（key `recommend:{algo}:{user|title|keywords}`）。

## 5. 算法引擎契约（详细）

### 5.1 热度预测 predict_api.py

```
python predict_api.py --model <lr|knn|svm|dt|rf|lgbm>
    --budget <集数> --popularity <收藏数> --runtime <分钟>
    --language <语言> --status <类型> [--train]
输出：{"model":"lr","prediction":num,"currency":"members","metrics":{...},"trained_now":bool}
```

- 特征工程：`budget_log=ln(1+集数)`、`popularity_log=ln(1+收藏数)`、交互项；
- 缓存：`model_cache/predict_{model}.joblib`，不存在时自动训练（train.csv）。

### 5.2 推荐 recommend_api.py

```
python recommend_api.py --algo <10 选 1> [--user <id, 减10偏移>] [--movie <标题>] [--keywords <词>] [--top K]
输出：{"algo":"...","movies":[{"title","movieId","score"},...]}
```

| 算法 | 必需参数 | 实现 |
| --- | --- | --- |
| demographic | — | IMDB 加权评分 |
| content | --movie | TF-IDF 内容相似 |
| keyword | --movie | 关键词匹配 |
| user_knn / movie_knn | --user / --movie | Surprise KNN |
| svd | --user | Surprise SVD |
| ncf | --user | PyTorch NeuMF(GMF+MLP)，缓存 ncf.pt |
| knn_svd / usr_movie_knn / usr_keywords | 组合 | 集成策略 |

## 6. 关键流程详细设计

### 6.1 登录会话流程

```
浏览器 → POST /api/user/login → RestLoginAuthenticationFilter
  → RestAuthenticationProvider.authUser()（密码校验）
  → principal = new UserDetails(username, password, ROLE)
  → HttpSessionSecurityContextRepository 写入 Session → Redis
  → 响应 {code:1}；后续请求携带 SESSION Cookie 自动恢复安全上下文
```

### 6.2 推荐调用链

```
前端 /recommend → POST /api/recommend {algo,userId,movieTitle,keywords,top}
  → RecommendServiceImpl.validate()（参数校验）
  → 查 Redis 缓存（1h）命中直接返回
  → ProcessBuilder 调 recommend_api.py（相对路径 ../.venv/...）
  → 解析 stdout 最后一行 JSON → enrich() 回填评分/海报
  → 写缓存 → 返回 List<RecommendItemVM>
```

### 6.3 热度榜初始化

`HeatInitRunner`（ApplicationRunner）启动时计算全部动漫 `heat_score`
（综合评分、成员数、评分人数的加权），供主页 TOP10 与列表排序使用。

## 7. 异常与边界设计

| 场景 | 处理 |
| --- | --- |
| 未登录访问受保护接口 | 401 JSON，前端拦截跳登录 |
| 推荐算法缺参数 | Java 侧 validate 抛 IllegalArgumentException（提示填 userId/movieTitle） |
| Python 调用失败 | 捕获异常 → 500 + 错误信息，不中断服务 |
| 用户不存在于协同过滤训练集 | Python 报 `not part of the trainset`，Java 前端提示更换用户ID |
| ECharts/静态资源 404 | 已移除失效第三方引用，页面不再加载失败脚本 |
