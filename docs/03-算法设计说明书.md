| 步骤 | 方法 | 设计理由 |

| 交互特征 | $budget' \times runtime'$ | 捕获"集数×时长"的复合影响 |

## 2. 通用评估指标

### 2.1 回归指标（热度预测）

**均方根误差 RMSE**
$$
\text{RMSE} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}
$$

**平均绝对误差 MAE**
$$
\text{MAE} = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|
$$

**决定系数 R²**
$$
R^2 = 1 - \frac{\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{n}(y_i - \bar{y})^2}
$$

> 说明：指标在**原始量纲（成员数）** 上计算，保证业务可解释性。

### 2.2 推荐指标

**Precision@K / Recall@K**
$$
\text{Precision@K} = \frac{|\text{推荐TopK} \cap \text{真实喜欢}|}{K}, \quad
\text{Recall@K} = \frac{|\text{推荐TopK} \cap \text{真实喜欢}|}{|\text{真实喜欢}|}
$$

**NDCG@K（考虑排序位置）**
$$
\text{NDCG@K} = \frac{\text{DCG@K}}{\text{IDCG@K}}, \quad
\text{DCG@K} = \sum_{i=1}^{K}\frac{2^{rel_i}-1}{\log_2(i+1)}
$$

**评分预测误差（协同过滤）**：RMSE / MAE（同上）

## 3. 热度预测算法设计（6 种机器学习）

> **任务定义**：给定动漫的集数、成员数、单集时长、原始语言、类型，预测其热度（成员数）。
> **数学形式**：$f: \mathbb{R}^3 \times \mathcal{C}^2 \rightarrow \mathbb{R}$，
> 其中 $\mathcal{C}$ 为类别集合。

```
输入特征（6 维，经特征工程后）：
   budget_log      = ln(1 + 集数)
   popularity_log  = ln(1 + 收藏数)
   runtime         = 单集时长(分钟)
   interact        = budget_log × ln(1+runtime)
   lang_code       = 语言编码
   status_code     = 类型编码
标签：
   y = ln(1 + 成员数)        ← 训练时
预测输出：
   ŷ = expm1(模型输出)       ← 还原到原始量纲
```

---

### A1. 线性回归（Linear Regression）

**原理**：假设特征与目标存在线性关系，最小化残差平方和。

**模型**
$$
\hat{y} = w_0 + \sum_{j=1}^{k} w_j x_j
$$

**损失函数（最小二乘）**
$$
J(w) = \frac{1}{2n}\sum_{i=1}^{n}\left(y_i - \hat{y}_i\right)^2
$$

**求解**：正规方程 $w = (X^TX)^{-1}X^Ty$，或梯度下降。

| 项目 | 设计 |
| --- | --- |
| 输入 | 6 维标准化特征 |
| 输出 | 预测对数热度 |
| 超参数 | 无（解析解） |
| 预处理 | **StandardScaler 标准化（必需）** |
| 优点 | 训练极快、可解释（系数即特征重要性） |
| 缺点 | 无法拟合非线性关系 |
| 定位 | **性能下界基线** |

---

### A2. K 近邻回归（K-Nearest Neighbors）

**原理**：对样本 $x$，找训练集中最近的 $k$ 个邻居，以其标签加权平均作为预测。

**模型（距离加权）**
$$
\hat{y}(x) = \frac{\sum_{i \in N_k(x)} w_i \, y_i}{\sum_{i \in N_k(x)} w_i}, \quad w_i = \frac{1}{d(x, x_i)}
$$

**距离度量（欧氏）**
$$
d(x, x_i) = \sqrt{\sum_{j=1}^{k}(x_j - x_{ij})^2}
$$

| 项目 | 设计 |
| --- | --- |
| 超参数 | `n_neighbors=5`，`weights='distance'` |
| 预处理 | **StandardScaler 标准化（必需，否则量纲主导距离）** |
| 优点 | 无需训练、可拟合局部非线性 |
| 缺点 | 预测需遍历全表、对稀疏高维敏感 |
| 定位 | 非参数基线 |

---

### A3. 支持向量回归（SVR）

**原理**：寻找一个"管道"（$\epsilon$-tube）包住尽可能多的样本，允许管道外样本的松弛，用核函数映射到高维空间处理非线性。

**优化目标**
$$
\min_{w,b,\xi,\xi^*} \frac{1}{2}\|w\|^2 + C\sum_{i=1}^{n}(\xi_i + \xi_i^*)
$$
$$
\text{s.t.}\quad y_i - (w^Tx_i + b) \le \epsilon + \xi_i,\quad
(w^Tx_i + b) - y_i \le \epsilon + \xi_i^*,\quad \xi_i,\xi_i^* \ge 0
$$

**对偶 + 核技巧（RBF 核）**
$$
K(x_i, x_j) = \exp\left(-\gamma\|x_i - x_j\|^2\right)
$$

| 项目 | 设计 |
| --- | --- |
| 超参数 | `kernel='rbf'`, `C=10.0`, `gamma='scale'`, `epsilon=0.1` |
| 预处理 | **StandardScaler + 目标对数变换（必需）** |
| 优点 | 小样本泛化好、核方法处理非线性 |
| 缺点 | $O(n^2)$~$O(n^3)$，对量纲与超参敏感 |
| 定位 | 核方法代表 |

---

### A4. 决策树回归（Decision Tree）

**原理**：递归选择最优特征与切分点，将空间划分为矩形区域，叶子节点输出区域均值。

**切分准则（最小化加权 MSE）**
$$
\text{For } (j, s): \quad \min_{j,s}\left[\min_{c_1}\sum_{x_i \in R_1(j,s)}(y_i-c_1)^2 + \min_{c_2}\sum_{x_i \in R_2(j,s)}(y_i-c_2)^2\right]
$$

| 项目 | 设计 |
| --- | --- |
| 超参数 | `criterion='squared_error'`, `random_state=42` |
| 优点 | 可解释（可导出可视化树）、无需标准化 |
| 缺点 | 易过拟合、方差大 |
| 定位 | 树模型基线，也是 A5/A6 的基学习器 |

---

### A5. 随机森林（Random Forest）

**原理**：Bagging 集成 —— 对样本有放回抽样 + 对特征随机子集采样，训练多棵决策树，回归取平均。

**模型**
$$
\hat{y}(x) = \frac{1}{B}\sum_{b=1}^{B} T_b(x)
$$

其中 $T_b$ 为第 $b$ 棵在自助样本 $D_b$ 与随机特征子集上训练的树。

**泛化误差界**
$$
\text{PE}^* \le \frac{\bar{\rho}(1-s^2)}{s^2}
$$

（$\bar\rho$ 为树间相关系数，$s$ 为单树精度；降低相关性可降误差）

| 项目 | 设计 |
| --- | --- |
| 超参数 | `n_estimators=200`, `random_state=42`, `n_jobs=-1` |
| 优点 | 抗过拟合、无需标准化、可输出特征重要性 |
| 缺点 | 模型体积大、预测慢于单树 |
| 定位 | **主力模型之一** |

---

### A6. LightGBM（梯度提升决策树）

**原理**：Boosting 集成 —— 串行训练弱学习器，每棵新树拟合前面模型的残差。

**加法模型**
$$
F_m(x) = F_{m-1}(x) + \nu \cdot h_m(x)
$$

其中 $\nu$ 为学习率，$h_m$ 为第 $m$ 棵拟合负梯度的树。

**核心优化（相对 XGBoost）**
1. **直方图算法**：连续特征分桶，降低分裂点搜索复杂度
2. **Leaf-wise 生长**：每次分裂增益最大的叶子，同层数下精度更高
3. **GOSS 采样**：保留大梯度样本 + 随机采样小梯度样本
4. **EFB 特征捆绑**：互斥稀疏特征合并，降维

| 项目 | 设计 |
| --- | --- |
| 超参数 | `learning_rate=0.05`, `num_leaves=31`, `feature_fraction=0.8`, `bagging_fraction=0.8`, `num_boost_round=500` |
| 优点 | 表格数据 SOTA、训练快、精度高 |
| 缺点 | 小样本易过拟合、参数较多 |
| 定位 | **主力模型，预期最优** |

## 4. 深度学习算法设计

### A7. NCF 神经协同过滤（Neural Collaborative Filtering）★

**原理**：用神经网络替代矩阵分解中的**内积**操作，学习用户与物品的**非线性交互**。
本项目采用 **NeuMF（Neural Matrix Factorization）** 结构，融合 GMF 与 MLP 两条分支。

#### 4.1 模型结构

```
         用户 u                          动漫 i
           │                               │
    ┌──────┴──────┐                 ┌──────┴──────┐
    │ User Emb    │                 │ Item Emb    │
    │ (GMF 分支)  │                 │ (GMF 分支)  │
    │ p_u ∈ R^32  │                 │ q_i ∈ R^32  │
    └──────┬──────┘                 └──────┬──────┘
           │      ① GMF：逐元素积            │
           └────────► p_u ⊙ q_i ◄───────────┘
                          │ (32维)
    ┌─────────────────────┴─────────────────────┐
    │                                            │
    │  User Emb(MLP)  p'_u  ─┐                   │
    │                        ├─► concat [p'_u; q'_i] (64维)
    │  Item Emb(MLP)  q'_i  ─┘                    │
    │                     │                       │
    │          ② MLP：全连接层堆叠                 │
    │   64 → 32 → 16 → 8  (ReLU + Dropout)        │
    │                     │ (8维)                  │
    └─────────────────────┼───────────────────────┘
                          │
              ③ 融合 concat [GMF(32); MLP(8)] = 40维
                          │
              ④ 输出层 Linear(40 → 1)
                          │
                   r̂_ui（预测评分残差）
       最终预测：  r̂ = μ_global + r̂_ui
```

#### 4.2 数学表达

**GMF 分支**
$$
\phi^{GMF} = p_u \odot q_i
$$

**MLP 分支**
$$
\phi^{MLP} = a_L\left(W_L\left(\cdots a_1(W_1[p_u'; q_i'] + b_1)\cdots\right) + b_L\right)
$$

**NeuMF 融合层**
$$
\hat{r}_{ui} = \sigma\left(h^T[\phi^{GMF}; \phi^{MLP}]\right), \quad
\text{本项目采用线性输出：} \hat{r}_{ui} = h^T[\phi^{GMF}; \phi^{MLP}] + b
$$

**最终评分**
$$
\hat{r}_{ui}^{final} = \mu + \hat{r}_{ui}
$$
（$\mu$ 为全局平均分，模型只学习残差，加速收敛）

#### 4.3 损失函数

$$
\mathcal{L} = \frac{1}{|\mathcal{D}|}\sum_{(u,i) \in \mathcal{D}}\left(r_{ui} - \hat{r}_{ui}^{final}\right)^2 + \lambda\|\Theta\|^2
$$

MSE + L2 正则（weight decay）。

#### 4.4 训练配置

| 项目 | 设置 | 设计理由 |
| --- | --- | --- |
| 框架 | PyTorch（CPU） | 本地无 GPU，模型规模小 |
| Embedding 维度 | GMF 32 / MLP 32 | 数据量 8 万，避免过拟合 |
| MLP 结构 | 64→32→16→8 | 逐层降维，漏斗结构 |
| 激活函数 | ReLU | 缓解梯度消失 |
| Dropout | 0.2 | 正则化 |
| 优化器 | Adam, lr=1e-3 | 自适应学习率 |
| 批大小 | 256 | CPU 内存友好 |
| 训练轮数 | ≤ 20（早停 patience=3） | 防过拟合 |
| 验证集 | 从训练集再切 10% | 早停依据 |
| 模型缓存 | `model_cache/ncf.pt` | 避免重复训练 |

#### 4.5 推理流程

```
输入：用户 u、候选动漫集合 C（用户未评分的高人气动漫 Top1000）
  → 用户嵌入查表 → 与所有候选动漫嵌入配对
  → 批量前向传播 → 得到所有候选的预测评分
  → 按预测评分降序 → 取 Top-K → 映射回 MAL id → 输出
```

#### 4.6 与矩阵分解的对比

| 维度 | SVD（A8） | NCF（A7） |
| --- | --- | --- |
| 交互函数 | 内积（线性） | MLP（非线性） |
| 表达能力 | 低秩线性 | 任意连续函数逼近 |
| 稀疏鲁棒性 | 一般 | 更好（共享嵌入） |
| 训练成本 | 低（闭式/ALS） | 高（反向传播） |
| 可解释性 | 强（隐因子） | 弱（黑盒） |

> **定位**：NCF 作为深度学习代表，与 SVD/KNN 形成「线性-非线性」「浅层-深层」的对比实验。

## 5. 推荐算法设计（协同过滤与内容推荐）

### A8. SVD 矩阵分解（Surprise SVD）

**原理**：将评分矩阵 $R_{m \times n}$ 分解为用户/物品隐因子，同时引入偏置项。

**预测公式（带偏置的 FunkSVD）**
$$
\hat{r}_{ui} = \mu + b_u + b_i + q_i^T p_u
$$

**目标函数**
$$
\min_{p,q,b}\sum_{(u,i)\in\mathcal{D}}\left(r_{ui} - \mu - b_u - b_i - q_i^Tp_u\right)^2
+ \lambda\left(\|p_u\|^2 + \|q_i\|^2 + b_u^2 + b_i^2\right)
$$

**优化**：随机梯度下降（SGD）或交替最小二乘（ALS）。

| 项目 | 设计 |
| --- | --- |
| 库 | scikit-surprise `SVD` |
| 评估 | 5-fold 交叉验证 RMSE |
| 定位 | 缓解 98.9% 稀疏的经典方法 |

### A9. 协同过滤 KNN

**User-based（找相似用户）**
$$
\hat{r}_{ui} = \bar{r}_u + \frac{\sum_{v \in N_k(u)} \text{sim}(u,v)\,(r_{vi}-\bar{r}_v)}{\sum_{v \in N_k(u)}|\text{sim}(u,v)|}
$$

**Item-based（找相似物品）**
$$
\hat{r}_{ui} = \frac{\sum_{j \in N_k(i)} \text{sim}(i,j)\,r_{uj}}{\sum_{j \in N_k(i)}|\text{sim}(i,j)|}
$$

**相似度（余弦 / 皮尔逊）**
$$
\text{sim}(u,v) = \frac{\sum_i r_{ui}r_{vi}}{\sqrt{\sum_i r_{ui}^2}\sqrt{\sum_i r_{vi}^2}}
$$

| 项目 | 设计 |
| --- | --- |
| 库 | scikit-surprise `KNNBaseline` |
| 优点 | 直观、可解释（相似用户/物品） |
| 缺点 | 稀疏下覆盖率低、内存开销大 |

### A10. TF-IDF 内容推荐

**原理**：将动漫简介/标签转为 TF-IDF 向量，用余弦相似度度量内容相似。

**TF-IDF**
$$
\text{tfidf}(t,d) = \text{tf}(t,d) \times \log\frac{N}{\text{df}(t)}
$$

**余弦相似度**
$$
\text{sim}(d_1,d_2) = \frac{\vec{v}_1 \cdot \vec{v}_2}{\|\vec{v}_1\|\,\|\vec{v}_2\|}
$$

| 项目 | 设计 |
| --- | --- |
| 库 | scikit-learn `TfidfVectorizer` + `cosine_similarity` |
| 用途 | 详情页「相似番剧」、动漫属性推荐 |

### A11. IMDB 加权评分（人口统计推荐）

**原理**：解决"小样本高评分"偏差，用贝叶斯加权融合全局均值。

$$
\text{WR} = \frac{v}{v+m}\,R + \frac{m}{v+m}\,C
$$

其中 $v$ 为评分人数，$m$ 为进入榜单所需最小票数（取全体均值），$R$ 为动漫均分，$C$ 为全体均分。

| 项目 | 设计 |
| --- | --- |
| 用途 | 全局热门榜兜底推荐 |
| 优点 | 无需用户信息、冷启动友好 |

### A12. 集成推荐（混合策略）

| 算法 | 策略 |
| --- | --- |
| KNN + SVD | User-KNN 取候选 → SVD 评分精排 |
| KNN + 关键词 | User-KNN 取候选 → TF-IDF 关键词相似精排 |
| KNN + Item-KNN | User-KNN 取候选 → Item-KNN 精排 |

$$
\text{score}_{final} = \alpha \cdot \text{score}_{recall} + \beta \cdot \text{score}_{rank}
$$
