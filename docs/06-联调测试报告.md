## 5. 联调期间发现并修复的问题

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| JDK 25 下 Spring Session Redis 反序列化不兼容 | 登录态丢失、页面全 0 | 统一 JDK 17 编译运行（pom 17），重启脚本内置 JDK 17 |
| 主页引用被移除的全局 echarts | mounted 抛 ReferenceError，统计全 0 | 改为 `import * as echarts from 'echarts'` + 注册 macarons 主题 |
| 动漫属性分析空图 | 上映年份/时长/预算为 NULL | 运行 `scripts/data_prep/enrich_video_info.py` 补全 4980 部 |
| 登出 NPE（authentication 为 null） | 无法登出 | RestLogoutSuccessHandler 增加空指针与类型防御 |
| index.html 引用缺失的 ueditor/echarts 脚本 | 404 刷屏 | 移除失效引用并重建前端 |
